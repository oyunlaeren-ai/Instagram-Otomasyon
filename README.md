## Instagram API Limitations

- Resmi Instagram API ile başka hesapları takip etme desteklenmez.
- Resmi Instagram API ile başka hesapları takipten çıkarma desteklenmez.
- Genel takipçi/takip edilen kullanıcı listeleri sağlanmaz.
- `followers_count` ve `follows_count` gibi sayısal profil alanları alınabilir.
- Uygulama bu işlemler için sahte başarı üretmez.
