# Instagram-Otomasyon

Instagram hesaplarında tekrar eden işlemleri otomatikleştirmek için planlanan proje deposu.

## Durum

Bu depo şu anda ilk kurulum aşamasındadır; henüz çalışan uygulama kodu eklenmemiştir.

## Hedeflenen kapsam

- Hesap oturumu ve temel otomasyon akışları
- Gönderi veya içerik paylaşım süreçleri
- Yapılandırma ve çalışma kayıtları için temel altyapı
